# 作业登记

托管老师用的作业登记与反馈工具。单文件 PWA，打开就能用，数据存在本机浏览器里，不上传任何服务器。

线上地址：https://homework-log-39980.app.workbuddy.host/

## 它做什么

- **拍照识题**：拍老师发的作业照片，可先裁剪只留作业区域，OCR 自动拆成一条条作业，可手动增删改
- **逐项登记**：每项作业标状态（已完成 / 没写完 / 已上交 / 回去做），可多选标签（全对、正确率高、字迹工整、粗心很多、字迹不工整、需订正）+ 手写备注
- **按学科分组**：语文、数学、英语 + 自定义学科，同学科的作业排在一起
- **同班复制**：一个学生的作业可以一键复制给同班其他人
- **自动写反馈**：按登记情况生成家长反馈文案，可按天、也可按周（周范围可自定义起止日期，应对调休）
- **可换主题色**：8 个预设色 + 任意取色，刷新后保持

## 反馈文案的规则

- 完成且没有备注、没有标签的作业**不逐条列出**，统一并成一句「其他作业已全部完成并订正」
- 「回去做」指只能回家由家长陪同完成的作业，文案写成「回家和您一起完成」，不写「没做完带回去补」
- 「没写完」是单独的状态，承诺次日陪补
- 语气按家长视角写得口语化，结尾留一句可对话的话

## 数据怎么存

全部存在浏览器 `localStorage`（键 `hwbook.v1`），代码里**没有任何 fetch / XHR / sendBeacon**，数据不出本机。

因此：

- 换手机、清缓存、换浏览器 = 数据丢失，需在「名单」页用「备份数据」导出 JSON
- 把备份文件发给别人，对方「恢复备份」即可拿到同一份名单
- 两人各自打开同一个链接，数据互不相通

## 关于全屏

网页里的 Fullscreen API 在手机上锁不住方向：安卓浏览器进全屏会当成视频场景自动转横，`screen.orientation.lock()` 在多数国产浏览器和微信里没有实现。

所以这里**不调用全屏 API**，改为引导「添加到主屏幕」（PWA）。装到桌面后由 `manifest.webmanifest` 的 `orientation: "portrait"` 决定方向，是系统级窗口，浏览器改不了。

横屏时也不做任何遮挡，只压薄上下栏，保证永远能操作。

## 文件

```
index.html              全部应用（HTML + CSS + JS，无框架无构建）
manifest.webmanifest    PWA 配置，锁竖屏
sw.js                   Service Worker，离线缓存
icon-180.png            iOS 主屏图标
icon-192.png / icon-512.png / icon-maskable-512.png
作业登记-扫码打开.png    线上地址的二维码
```

## 技术

原生 HTML / CSS / JS，零依赖、零构建。OCR 用 tesseract.js 5.1.0（经 unpkg 加载，中文语言包约 1.7MB 量化版）。

## 本地打开

直接双击 `index.html` 就能用；要测 PWA 和 Service Worker 需起个本地服务，例如 `python -m http.server`。
